## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas na Universidade Presbiteriana Mackenzie**, com foco em desenvolvimento **Back-end Java** e construção de aplicações Full Stack.

Tenho desenvolvido projetos de ponta a ponta utilizando **Java, Spring Boot, React, TypeScript, PostgreSQL, Docker e AWS**, trabalhando com APIs REST, autenticação e autorização, bancos de dados relacionais, testes, CI/CD e deploy de aplicações.

Gosto de transformar conceitos em sistemas funcionais, buscando aplicar boas práticas de arquitetura, segurança, qualidade de código e experiência do usuário.

🎯 Atualmente busco uma oportunidade de **Estágio ou Desenvolvedor Júnior**, principalmente na área de desenvolvimento de software.
